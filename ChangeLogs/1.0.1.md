# 1.0.1
1. Obase.OdmGenerator.Agent
   - 领域类信息中增加类的注释,领域信息分析器支持提取类声明前的文档注释.
   - 增加根据领域类名称查询类的注释的工具,并在领域类信息检索结果中附带类的注释.
   - 增加默认的ODM配置审核检查项,支持通过审核要求参数自定义审核规则,不指定时使用由配置生成规则与默认审核检查项组成的审核要求.
   - 配置生成规则拆分为带前言与不带前言两种输出,便于在审核场景中复用配置规则.
   - 向单元测试项目公开内部类型,以便对内部的规则与代理进行测试.
2. Obase.OdmGenerator.WorkFlow
   - GetWorkFlowWithExecutor方法的各个执行器参数均改为可空,未指定的执行器使用默认构造的执行器.
   - GetWorkFlowWithExecutor方法增加领域类信息,编程语言与LLM配置参数,用于构造未指定的执行器,并对领域类信息与LLM配置进行非空校验.
   - GetDefaultWorkflowBuilder方法改为复用默认的执行器构造逻辑.
   - ODM配置审核执行器增加审核要求参数,支持自定义审核规则.
